# BLIIOT Documentation Library

Welcome to the BLIIOT developer documentation center.

This site brings together public technical materials across the product line, including quick-start deployment guides, Node-RED workflow tutorials, industrial protocol references such as Modbus, OPC UA, and CAN, hardware specifications, wiring manuals, and industry solution notes.

## Highlights

- Quick deployment guides for industrial edge devices
- Node-RED low-code workflow tutorials
- Industrial communication references for Modbus, OPC UA, and CAN
- Hardware specifications and user manuals
- Software product introductions and usage guidance
